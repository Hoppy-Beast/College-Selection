An editorial, high-performance web platform designed and owned by **MD. Mahinur Rahman Prachurza (Prachurza)** in collaboration with **Fahad's Tutorial (FT)** to help **SSC-26 Graduates and Parents in Bangladesh** discover, compare, and rank top **HSC Colleges** across all 64 districts in Bangladesh based on official Education Board Result Publication analytics.

## ✨ Key Features (v4.0 Editorial Edition)

- **2-Click Multi-Sort Toggle Engine**: Click any metric pill once to turn it **ON** (add to priority ranks 1st, 2nd, 3rd) and click again to turn it **OFF**. 2 clicks maximum!
- **Human Non-AI Editorial Design**: Designed using **Space Grotesk** headings, sharp structural boundaries, high-contrast dark carbon theme, and zero emojis.
- **Fahad's Tutorial Marketing Callout**: Features a dedicated marketing card with direct links to [Fahad's Tutorial Platform](https://ft.education/).
- **Nationwide Coverage (2,750+ Colleges)**: Complete coverage across all 11 Education Boards in Bangladesh (Dhaka, Rajshahi, Chittagong, Comilla, Sylhet, Barisal, Dinajpur, Jessore, Mymensingh, Madrasah, Technical).
- **Average GPA-5 Rate Analytics**: Highlights the Average GPA-5 Rate across all subjects as the primary academic excellence metric.
- **60fps Mobile & Desktop Responsive**: GPU-hardware-accelerated, debounced search, and fluid layout optimized for both smartphones and desktop screens.
- **Important Legal & Candidate Notes**: Clear disclaimers advising students to verify official Ministry eligibility rules on `xiclassadmission.gov.bd`.

## 🚀 How to Host on GitHub Pages (3 Simple Steps)

1. **Push Repository to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - HSC College Selection Portal by Prachurza & FT"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository **Settings** on GitHub.
   - Select **Pages** from the left navigation menu.
   - Under **Source**, choose `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder, then click **Save**.

3. **Done!**:
   - Your site will be published live at `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/` in 1–2 minutes!
